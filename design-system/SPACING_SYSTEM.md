# المسافات — إيقاع ٤

`SinaatySpace`: `xs 4 · sm 8 · md 12 · lg 16 · xl 24 · xxl 32`. كل هامش وحشو من هذه القيم فقط.

## الاستعمال
| أين | القيمة |
|---|---|
| هامش الشاشة الجانبي | `lg` (16) — وعلى الشاشات ≥ 720 يُحصر العرض بـ`_Readable` |
| بين الأقسام | `xl` (24) |
| بين عنوان القسم ومحتواه | `sm` (8) |
| بين البطاقات داخل القسم | `md` (12) |
| حشو الورقة | `lg` (16) — الصفوف داخل ورقة `sm` أفقياً |
| حشو بطاقة الختم | 20 / 18 |
| بين عنصر ووصفه | `xs` (4) |
| فوق الشريط السفلي | `bottomClearance()` (68 + 14 + safe area + 8) — **لا رقم يُخمَّن** |

## الزوايا
| العنصر | نصف القطر |
|---|---|
| بطاقة الختم (البطل) | 20 |
| الورقة (بطاقة القسم، الجدول) | 14 |
| الزرّ، الحقل | 12 |
| الشارة | كاملة (999) |
| الصورة المصغّرة | 10 |

## الارتفاعات
زرّ رئيسي ٥٦ · زرّ ثانوي ٤٨ · صفّ قائمة ≥ ٥٦ · شريط التنقّل ٦٨ · حقل ٥٦.

## الظلّ — واحد
- **بطاقة الختم**: ظلّ واحد `sealDeep α.35 blur 32 y16 spread −12`.
- **الورق**: بلا ظلّ؛ حدّ `line` 1px. (كان ظلّ طبقتين على كل ورقة — يُلغى.)
- **الشريط السفلي**: حدّ علوي فقط.
- **الزرّ الرئيسي**: بلا ظلّ (كان توهّجاً أخضر — يُلغى؛ اللون يكفي).
