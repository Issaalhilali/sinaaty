# الطباعة — Almarai بثلاث درجات

الخط: **Almarai** (400 / 700 / 800) مضمّن، للعربية والإنجليزية معاً. لا `letterSpacing` سالب أبداً مع العربية. الأرقام غربية + `tabularFigures` لكل مبلغ ورقم مرجعي وعدّاد.

## المقياس (كما في `AppTheme` — المالك طلب سُلّماً أهدأ: «بعض الجمل كبيرة»)
| الدور | Material | الحجم / الوزن / الارتفاع | أين |
|---|---|---|---|
| **البطل الرقمي** | headlineMedium | 24 / w800 / 1.4 | `MoneyText(hero)` — المبلغ وحده يأخذ w800 |
| عنوان كبير | headlineSmall | 20 / w600 / 1.45 | شاشات التعريف والحالات النادرة |
| عنوان الشاشة / البطاقة البطل | titleLarge | 18 / w600 / 1.45 | رأس الشاشة، اسم الطلب داخل الختم |
| عنوان بطاقة | titleMedium | 16 / w600 / 1.5 | عنوان داخل ورقة |
| عنوان صفّ | titleSmall | 15 / w600 / 1.5 | `AppListRow` |
| نص | bodyMedium | 14 / w400 / 1.6 | كل قراءة |
| نص طويل | bodyLarge | 15 / w400 / 1.65 | شروط، شرح قانوني |
| **عنوان القسم (eyebrow)** | labelLarge | 13 / w600 / 1.3، لون `ink2` + شريط `seal` | `SectionTitle` |
| وصفي | bodySmall | 12.5 / w400 / 1.6، `muted` | الرقم المرجعي، التاريخ |
| شارة / تسمية | labelSmall | 12 / w400–700 | `StatusBadge`، تسميات صغيرة |

## قواعد
1. **ثلاث درجات في الشاشة الواحدة كحدٍّ أقصى** بين البطاقات: عنوان القسم، عنوان الصفّ، الوصفي. البطل يضيف الرابعة داخله فقط.
2. **العريض (≥ w700) للمبلغ وحده** — قرار المالك المقاس في `test/palette_test.dart` («كل شيء عريض فلا شيء يبرز»). العناوين w600، القراءة w400.
3. العنوان يُقرأ في سطرين كحدٍّ أقصى ثم `ellipsis` — الاسم الطويل يُختصر لا يكسر البطاقة.
4. الأرقام داخل النص العربي تُعزل بـ`textDirection: ltr` عند الحاجة (`Fmt`).
5. لا نصّ بأقل من ١٢.٥؛ لا نص على الختم بأقل من ١٣.
6. الإنجليزية بنفس المقياس؛ لا ترجمة حرفية للأحجام.
