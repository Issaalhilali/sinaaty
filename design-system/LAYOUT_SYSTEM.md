# التخطيط — عمود واحد يقرأ من اليمين

## الجوال (الأساس)
- عمود واحد، عرض قراءة ≤ 720 (`_Readable` في `AppScaffold`). على الأجهزة اللوحية يبقى العمود في المنتصف بأرضية حوله — لا شبكة أعمدة على الجوال.
- ترتيب الشاشة الثابت: **العنوان → (تنبيه قديم/غير متصل) → البطل → الإجراءات الثانوية → الأقسام → الشريط السفلي**.
- الشريط السفلي: الفعل الرئيسي وحده. لا زرّين متجاورين إلا «إلغاء/تأكيد» في ورقة.
- الورقة السفلية (`SheetBody`) للأفعال القصيرة (سعر، تأكيد، عدد)؛ شاشة كاملة لما يحتاج تمريراً أو كاميرا.

## القوائم
- **صفوف لا بطاقات**: `RowGroup` داخل ورقة واحدة بفواصل مُزاحة. بطاقة مستقلة فقط للكيان الذي يحتاج زرّاً داخله.
- الصفّ: أيقونة (٤٤) · عنوان + وصفي · شارة واحدة أو قيمة · سهم.
- القوائم الطويلة (> ٨) تُقسَّم بشرائح علوية (`SegmentedButton`) لا بتمرير واحد طويل.

## الشبكة
- تُستعمل مرة واحدة: الفحص ٨ زوايا (٢×٤) وملصقات QR (٢ أعمدة). **لا شبكة خدمات**؛ الخدمات صفّ أفقي من ثلاثة أزرار كبيرة + «المزيد».

## اللوحة (ويب)
- قائمة جانبية ٢٤٠px بأربع مجموعات؛ محتوى بعرض أقصى 1200؛ صفحة = عنوان + KPI واحد مختوم + جدول واحد قياسي + لوحة جانبية للقرار.
- نقاط الكسر: < 1024 تنطوي القائمة إلى أيقونات؛ < 768 تصبح ورقة علوية (الاستعمال من الجوال نادر ومقبول بجودة أقل).

## RTL
كل شيء `Directional` (`EdgeInsetsDirectional`, `AlignmentDirectional`)؛ الأرقام والرموز LTR معزولة؛ سهم الصفّ يُقلب حسب الاتجاه (موجود في `AppListRow`).
