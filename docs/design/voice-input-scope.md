# نطاق: الصوت في كل الطلبات — توجيه المالك 2026-08-22 (محكَّم)

**التوجيه نصاً:** «أريد إضافة ميزة الصوت لتنفيذ كل الطلبات بجودة واحتراف عالي الجودة».
**التقسيم:** كله mobile (sinaaty-d0) — لا إضافات API (تحقُّق المراجعة: غرض `voice_note` قائم في
presign، و`POST /voice-notes` يقبل `media_id` صوتياً + `hint_ar` منذ Step 27).

## النطاق المعتمد

**(أ) قدرة موحدة `core/voice`:** منفذ `VoiceInput` قابل للحقن + تنفيذ فوق إملاء النظام على الجهاز
(`speech_to_text` — محركا آبل/قوقل بالعربية) + ورقة تسجيل بهوية الختم (مايك نابض، نص حي، أعد/تم)
+ زر مايك يلتصق بأي حقل نصي بسطر واحد، **ويختفي كلياً حين يقول المنفذ إن الإملاء غير متاح**.

**(ب) المايك في كل نقاط الإنشاء:** وصف «أصلح سيارتي»، اسم القطعة في ورقتي المزاد، ملاحظات
السطحة، رسالة النزاع، شكوى أمر العمل الجديد. *(بلا بوابة علم — الإملاء وسيلة إدخال كلوحة
المفاتيح، لا ميزة منتج؛ غيابه التقني هو ما يخفيه.)*

**(ج) «أملِ البنود صوتاً» للورشة** (يغلق بند Step 27 المتأخر — backlog 71): تسجيل فعلي
(حزمة `record`) يُرفع عبر presign بغرض `voice_note` **قبل** النداء (media_id إلزامي في الـ API
والملف يجب أن يكون `audio/*`) + الإملاء الحي `hint_ar` → مقترحات الاستخراج للمراجعة والتسعير
(`heard_ar` و`needs_price`) → apply عبر مسار البنود الطبيعي بإعادة الاعتماد.
**خلف علم `voice_to_invoice`** (مطفأ افتراضياً — تفعيل تدريجي من صفحة الأعلام).

## حسم توطين البيانات (يُكتب لا يُفترض)

إملاء النظام قد يمر بخوادم آبل/قوقل بحسب الجهاز واللغة — **الموقف الموثق**: الإملاء وسيلة إدخال
يملكها المستخدم (مكافئ زر المايك في لوحة مفاتيحه)، والتطبيق لا يرسل صوتاً لأي مزود من طرفه؛
الصوت الخام يذهب إلى تخزيننا فقط عبر presign. قرار مزود STT السحابي يبقى كما هو
(`INTEGRATION_SPEECH=live` مرفوض حتى اختيار مزود بإقامة سعودية — `docs/integrations/speech.md`،
وتُضاف إليه فقرة هذا الموقف). لا ADR جديد — لا يغادر التطبيقَ شيء.

## القبول

1. إملاء في ورقة «أصلح سيارتي» يملأ الوصف (منفذ محقون بنص ثابت).
2. تدفق voice-to-invoice كاملاً: تسجيل → رفع → مقترحات → تسعير المراجع → apply بالبنود الظاهرة
   في الأمر — وعلم `voice_to_invoice` المطفأ يُغيّب الشاشة كلياً.
3. **فشل الرفع لا يضيع شيئاً**: النص المُملى يبقى في الحقل وإعادة المحاولة معروضة.
4. غياب المايك حين يبلّغ المنفذ عدم التوفر؛ golden لورقة التسجيل وشاشة المراجعة (فاتح/داكن).
5. نصوص أذونات المايك/التعرف بالعربية في iOS وAndroid.
