# اليوم التجريبي الحي — دليل الجولة

ازرعه متى شئت (يشفي نفسه ويعيد الاستخدام):

```bash
node apps/api/tools/demo-day.mjs
```

يتطلب الـ API على :3000. أرقام الدخول أدناه — **رمز التحقق يظهر تلقائياً في شاشة الرمز** (بيئة تطوير).

| الدور | الرقم | التطبيق |
|---|---|---|
| مشعل — العميل | `+966533000001` | تطبيق العملاء |
| ورشة النخبة لصيانة تويوتا | `+966533000002` | تطبيق الشركاء |
| مركز الفحص الأول | `+966533000003` | تطبيق الشركاء |
| ورشة الاقتصاد | `+966533000004` | تطبيق الشركاء |
| قطع الأمانة | `+966533000005` | تطبيق الشركاء |
| سائق السطحة | `+966533000006` | تطبيق الشركاء |
| لوحة التحكم | `+966500000099` | `localhost:3001` |

## الجولة المقترحة — بترتيب الأثر

**١ · سوق الإصلاح (الجديد كلياً).** ادخل عميلاً → اطلب → طلباتي → «السيارة ترتج عند التسارع».
ثلاثة عروض متمايزة أمامك: النخبة (تشخيص فني، ٤٥٠–٧٠٠، **الآن**، شارتا «الأسرع» و«متخصصون في سيارتك»)،
الفحص الأول (**معاينة مجانية** بلا سعر — النظام رفض أن يحمل هذا النوع سعراً)، الاقتصاد (٣٨٠ — شارة
«الأرخص»، موعد غداً). كل عرض يقول **وينه** («الصناعية الثانية — ١٫٢ كم») وسرعة ردّ الورشة تاريخياً.
**اقبل ما يقنعك** — وسترى أمر عمل يولد فوراً عند الفائز، والخاسر يُعلَم.

**٢ · السلسلة القانونية.** إشعار «أمر بانتظار اعتمادك» → افتح «صيانة الـ ١٠٠ ألف» (٩٣٢٫٥٠ ر.س):
البنود مفصلة، والاعتماد **بتوقيعك عبر الرمز** على نسخة مختومة لا يستطيع أحد تعديلها بعدك.

**٣ · المال المحفوظ.** محفظتي → فاتورة البطارية (٥٤٠٫٥٠) مدفوعة والمبلغ «محفوظ حتى تستلم».
ثم ادخل بحساب النخبة → المحفظة: المبلغ في الطريق إليها. هذه فكرة المنصة المالية كاملة في شاشتين.

**٤ · مزاد القطع «بوينها».** اطلب → طلباتي → «مساعد أمامي»: عرضان — أصلي وكالة ٥٢٠ (ضمان ١٨٠ يوماً،
خلال ٣ ساعات) مقابل تجاري ٣٤٠ — وكل عرض يقول **أين القطعة والمسافة إليها**.

**٥ · السطحة.** طلب السطحة سُلّم بإثبات (صورة + رمزك) — والفاتورة ولدت وحدها وزر **«ادفع»**
ينتظرك في شاشة المهمة، والسعر هو نفسه الذي رأيته قبل الطلب، شاملاً الضريبة.

**٦ · عين المنصة.** لوحة التحكم :3001 — نظرة عامة، الدفعات والمبالغ المحفوظة (منها فاتورتك)،
وصندوق «بانتظار الاعتماد» لو طلب أحد استرداداً: المال لا يخرج إلا بعينين.
